# 대시보드

대시보드는 테넌트의 워크플로가 지금 어떻게 돌아가고 있는지 보여 줍니다. 진행 중인 실행, 승인을 기다리는 것, 실패한 것, 그리고 실행이 시작부터 완료까지 걸리는 시간입니다. 관리 사이드바 맨 위의 **대시보드**를 엽니다.

열어 둔 채로 쓰도록 만들어졌으며, 모든 수치는 15초마다 다시 읽힙니다. 보기는 두 가지이고, 선택한 보기는 브라우저가 기억합니다. 표준 보기는 앱의 다른 화면과 같은 모습이며 라이트 또는 다크 테마를 따릅니다. 미션 컨트롤 보기는 벽걸이 디스플레이용입니다. 앱의 나머지 부분이 어떤 테마이든 어두운 상태를 유지하고, 수치가 빛나며, 화면 어딘가가 항상 움직입니다.

두 종류의 실행은 어떤 수치에도 포함되지 않습니다. 아직 초안인 워크플로에서 시작한 테스트 실행과, [접근 제어 태그](./tags.md#access-control-tags) 때문에 나에게 숨겨진 실행입니다.

테넌트에서 아직 아무것도 실행하지 않았을 때 수치가 채워진 대시보드를 보려면 [데모 데이터](../getting-started/demo-data.md)를 로드하세요. 약 90일분의 가상 실행이 함께 등록됩니다.

## 도구 모음 {#the-toolbar}

| 컨트롤 | 하는 일 |
|---|---|
| **실시간** | 점은 수치가 최신임을 나타냅니다. 미션 컨트롤 보기에서는 점이 깜박이고, 다음 읽기가 가까워질수록 점을 둘러싼 고리가 줄어듭니다. 읽기에 실패하면 **연결 끊김**으로 바뀝니다. 이때 화면의 수치는 마지막으로 읽은 값이며, 대시보드는 계속 다시 시도합니다. |
| **7일** / **30일** / **90일** | **리드 타임**, **워크플로별 실행**, **확인 필요**가 다루는 기간을 정합니다. 타일과 나머지 패널은 항상 현재를 보여 줍니다. |
| **새로 고침** | 지금 모든 것을 다시 읽습니다. |
| **미션 컨트롤 보기로 전환** | 미션 컨트롤 보기로 바꿉니다. **표준 보기로 전환**으로 되돌립니다. 두 보기 모두 같은 수치를 보여 줍니다. |
| **전체 화면** | 화면 전체를 대시보드만으로 채웁니다. Esc 키나 **전체 화면 종료**로 돌아옵니다. |

## 타일 {#the-tiles}

각 타일은 숫자 하나, 보조 설명 한 줄, 그리고 페이지를 연 뒤로 숫자가 어떻게 움직였는지 보여 주는 선으로 이루어집니다. 미션 컨트롤 보기에서는 숫자가 바뀔 때마다 잠깐 밝게 빛납니다.

| 타일 | 숫자 | 아래 줄 | 색이 바뀌는 때 |
|---|---|---|---|
| **진행 중인 실행** | 진행 중인 실행(예약된 것 포함) | 최근 24시간 동안 시작된 실행 | 바뀌지 않음 |
| **대기 중인 승인** | 결정을 기다리는 승인 요청 | 오늘 결정된 승인 | 24시간 넘게 기다린 것이 있으면 호박색 |
| **오늘 완료** | 오늘 완료된 실행 | 실패한 작업 없이 완료된 비율 | 바뀌지 않음 |
| **실패한 실행(최근 24시간)** | 최근 24시간 동안 실패로 끝난 실행 | 같은 기간에 실패한 작업 | 0보다 크면 빨간색 |
| **메일 대기열** | 아직 보내지 않은 [알림 메일](./notifications.md#the-delivery-queue) | 가장 오래된 메일이 기다린 시간, 또는 전송에 실패한 건수 | 가장 오래된 메일이 5분 넘게 기다리면 호박색, 실패한 것이 있으면 빨간색 |

"오늘"은 서버 시간대의 자정에 시작합니다. [서버 설정](../operations/configuration.md#server-settings)을 참조하세요.

## 패널 {#the-panels}

| 패널 | 보여 주는 것 | 읽는 법 |
|---|---|---|
| **리드 타임** | 실행의 시작부터 완료까지 걸린 평균 시간을 실행이 완료된 날짜별로 보여 줍니다. 모서리의 수치는 기간 전체의 평균입니다. | 차트에 포인터를 올리거나, 차트에 포커스를 두고 화살표 키를 누르면 하루치를 읽을 수 있습니다. 아무것도 완료되지 않은 날에는 점이 없습니다. |
| **승인 적체** | 대기 중인 모든 승인입니다. 고리의 호박색 호는 24시간 넘게 기다린 비율입니다. 그 아래에 가장 오래 기다린 다섯 건이 있습니다. | **승인자**와 **워크플로**를 전환하면 승인이 누구를, 또는 어떤 워크플로를 기다리는지 볼 수 있습니다. 승인 중 하나라도 24시간 넘게 기다리면 막대가 호박색이 됩니다. |
| **워크플로별 실행** | 기간 동안 시작된 실행이 많은 순으로 워크플로 여덟 개를 보여 줍니다. 각 막대는 **완료됨**, **실패**, **실행 중**으로 나뉩니다. | 행 끝의 수치는 실행 수이며, 워크플로의 평균 리드 타임 옆에 있습니다. 구간에 포인터를 올리면 건수가 나옵니다. |
| **실패 원인** | 최근 24시간 동안 실패한 작업을 각각에 기록된 원인별로 보여 줍니다. | 범례에 해당하는 원인과 그 건수가 모두 나옵니다. |
| **확인 필요** | 기간 동안 실패한 작업이 있는 실행을 최신순으로, 원인과 함께 보여 줍니다. 관리자에게만 표시됩니다. | 실행을 클릭하면 열립니다. 띠를 옆으로 스크롤하면 나머지를 볼 수 있습니다. 미션 컨트롤 보기에서는 띠가 저절로 흐르고, 포인터가 올라가 있는 동안에는 멈춥니다. |

## 누가 볼 수 있나 {#who-sees-it}

**대시보드**는 관리자, 개발자, 요청자, 승인자의 사이드바에 표시됩니다. 테넌트에 대해 모두가 같은 수치를 봅니다. **확인 필요**만 관리자로 제한됩니다. 보는 사람이 참여하지 않았을 수도 있는 실행의 작업 이름과 실패 원인을 인용하기 때문입니다.

같은 수치를 자체 모니터링 도구에서 차트로 그리려면 [운영 메트릭](../operations/metrics.md)을 참조하세요.
