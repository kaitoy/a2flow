# 용어

이 도메인의 핵심을 이루는 개념들입니다. 서로 구분해서 알아 두면 좋습니다.

| 용어 | 의미 |
|---|---|
| **[워크플로](../guides/workflows.md)** | 미리 디자인해 두고 재사용하는 작업 단위입니다. 에이전트 스킬과 그 스킬에서 생성된 작업 템플릿으로 이루어집니다. |
| **디자인 세션** | 워크플로의 작업 템플릿을 만들고 다듬는 채팅입니다. 워크플로마다 정확히 하나가 있으며, 어떤 실행보다도 먼저 존재합니다. |
| **[워크플로 실행](../guides/workflow-executions.md)** | 워크플로의 1회 실행입니다. 실행 시점의 워크플로와 스킬 메타데이터를 스냅샷으로 보관하며, 해당 실행의 `WorkflowTask`, `Approval`, 메시지 메타데이터의 상위 레코드입니다. |
| **워크플로 세션** | 하나의 워크플로 실행이 진행되는 채팅으로, 디자인 세션에 대응하는 실행 시점의 세션입니다. |
| **분기 세션** | 실행의 작업 그래프가 갈라질 때 워크플로 세션에서 포크되는 세션으로, 해당 분기를 실행의 나머지 부분과 나란히 처리합니다. 맡은 작업이 끝나면 요약을 남기고 종료됩니다. |
| **[테넌트](./tenants.md)** | 최상위 조직 경계입니다. 거의 모든 레코드는 정확히 하나의 테넌트에 속하며, 어떤 요청도 한 테넌트에서 다른 테넌트로 넘어가지 않습니다. |
| **[사용자 그룹](../guides/users-and-groups.md#user-groups)** | 테넌트 안의 사용자를 이름을 붙여 묶은 것으로, 모든 구성원이 상속받는 역할 집합을 가집니다. |
| **[태그](../guides/tags.md)** | 시크릿, MCP 서버, 에이전트 스킬, 지식 베이스, 워크플로, 도구 모의, 사용자 그룹을 분류하는 테넌트 공통 레이블로, 일곱 가지가 하나의 어휘를 공유합니다. **액세스 제어**로 표시된 태그는 레이블이 붙은 레코드를 해당 태그를 가진 그룹의 구성원으로만 제한하기도 합니다. |
| **[에이전트 스킬](../guides/agent-skills.md)** | Git 저장소에 있는 `SKILL.md` 절차서로, 코드처럼 버전이 관리됩니다. 워크플로는 스킬에서 생성되고, 실행은 스킬의 게시된 리비전을 수행합니다. |
| **[지식 베이스](../guides/knowledge-bases.md)** | 등록된 웹 페이지와 문서를 바탕으로 LLM이 작성하는 위키로, 주제당 한 페이지로 구성됩니다. 여기에 연결된 워크플로에서는 디자인 에이전트와 실행 에이전트가 이곳에서 내용을 찾아봅니다. |
| **[MCP 서버](../guides/mcp-servers.md)** | 등록된 Model Context Protocol 서버로, 에이전트는 이 서버의 도구를 워크플로의 작업에 연결할 수 있습니다. |
| **[시크릿](../guides/secrets.md)** | 키/값 형식의 자격 증명 항목을 이름을 붙여 묶은 것입니다. 다른 곳에서는 `name/key` 형식으로 참조하며, 사용하는 시점에 지연 확인됩니다. |
| **[도구 인증서](../guides/approvals.md#human-approval)** | 작업이 MCP 도구를 호출할 때마다 제시해야 하는 수명이 짧은 X.509 인증서입니다. 승인이 부여될 때 또는 아무도 승인 요청을 받지 않은 작업이 시작될 때 발급되며, 발급 순간의 작업 도구 집합을 고정하고 누구의 권한을 지니는지 명시합니다. |
