# 工具模拟

工具模拟是一种替身，让**草稿**工作流的运行可以完整地从头走到尾，而不产生其工具的副作用。被模拟的工具不会被调用，而是返回模拟中配置的结果，因此不会有请求到达 MCP 服务器，不会记录审批，也不会有人收到邮件。

在管理侧边栏中打开**工具模拟**即可进行管理。

## 使用方法 {#using-one}

1. 为要替换的工具创建模拟。
2. 在**草稿**工作流上点击**运行**；如果工作流状态是 `已修改`，则在对话框中选择**未发布的编辑**。对话框的**模拟工具**下会列出替代此工作流某个任务所用工具的模拟，以及所有内置工具的模拟。
3. 勾选此次运行要使用的模拟，然后开始运行。

此工作流的任务都不使用的工具，其模拟不会出现在列表中，请先将该工具绑定到任务。只有[测试运行](./workflows.md#trying-the-edits-out)才提供模拟；运行已发布设计时，对话框不提供任何模拟，即使强行指定也会被拒绝。开始运行时，会把所选每个模拟的当前内容**复制**到这次执行上，因此之后编辑或删除模拟绝不会改变已在进行的运行，也绝不会悄悄地把被替换的调用变回真实调用。

模拟是**按工具**选择的，而不是按运行选择的，因为试运行只有保持真实才有用。先搜索某个系统再写入它的工作流可以只替换写入操作：读取操作仍访问真实服务器，代理仍基于真实数据进行推理。

## 模拟包含的内容 {#what-a-mock-holds}

| 字段 | 说明 |
|---|---|
| **名称** / **描述** | 用于在运行对话框中识别它。 |
| **目标** | [已注册 MCP 服务器](./mcp-servers.md)的一个工具（点击**选择 MCP 服务器**，选定服务器，再从该服务器加载的列表中选择**工具名称**），或一个 A2Flow **内置**工具。 |
| **响应** | 有序列表，按调用序号索引。 |

目前唯一可模拟的内置工具是 `request_approval`：这个工具的副作用原本需要有人处理，运行才能继续。

### 工具的返回内容 {#what-the-tool-returns}

选定工具后，其下方会展开**输出格式**，显示工具自身的描述以及它声明的返回结构。请以此为参考来编写下面的内容：模拟只有在工作流能像读取真实结果一样读取它时才有用。

并非每个工具都会声明返回内容。未声明时，面板会说明这一点，结构由您决定。

### 响应 {#responses}

第一个响应对应运行对该工具的第一次调用，第二个对应第二次，依此类推。列表用完后重复最后一个响应，因此只有一个响应时相当于常量。正因如此，一个模拟可以表达*场景*而不是固定值：批准第一个请求，驳回第二个，再看工作流如何处理这两种情况。

| 类型 | 含义 |
|---|---|
| 结构化（JSON 对象） | 放入结果结构化内容中的 JSON 对象，适用于调用方从结果中读取字段的工具 |
| 文本 | 放入结果文本内容中的字符串 |
| 错误 | 作为失败调用返回的消息，代理会看到工具报告错误 |

工具声明了输出格式时，**结构化（JSON 对象）** 响应会提供**从架构插入**：它会用该结构（包括所有键）填充输入框，这样您只需编辑值，不必抄写结构。它会替换输入框中的现有内容；如果您已经写了内容，会先询问。

## 标签 {#tags}

工具模拟的创建表单和详情页都有**标签**选择器，列表也有可筛选的**标签**列。这些标签与密钥、MCP 服务器及其他可加标签的注册表共用同一套租户级词汇，如何附加标签和按标签筛选，请参见[标签](./tags.md)。

## 模拟不会跳过的内容 {#what-a-mock-does-not-skip}

模拟跳过的是副作用，而不是规则。被模拟的调用仍要核对当前任务允许使用的工具，以及该任务正在等待的任何[审批](./approvals.md)，因此在生产环境中会被拒绝的工作流，在试运行中同样会被拒绝。它还要核对该审批允许的**输入**，因此试运行能拦下审批人本不会授权的调用，而不是让它蒙混过关。被模拟的审批请求仍会验证其目标及其声明的调用，因此指定了不符合条件的审批人的工作流，或者声明的调用与其步骤实际发出的调用不符的工作流，都会像真实运行那样在试运行中失败。

## 查看被模拟调用的结果 {#seeing-what-a-mocked-call-did}

被替换的调用可在运行的聊天记录中查看：展开其工具行即可看到参数和结果，并带有**已模拟**徽章。它特意不出现在运行的[工具调用](./workflow-executions.md#tool-invocations)页面上：该页面记录的是 MCP 网关实际作出的决定，而替身调用永远到不了那里。运行本身在[执行列表](./workflow-executions.md)中也带有**已模拟**徽章。
