# 租户

**租户**是 A2Flow 最高层级的组织边界。几乎每条记录都恰好属于一个租户，少数内容被有意置于所有租户之上，而任何请求都不会从一个租户跨入另一个租户。创建和编辑租户记录本身属于管理工作，请参阅[租户](../guides/users-and-groups.md#tenants)；本页讨论的是这条边界对其他一切内容意味着什么。

## 租户的范围 {#what-a-tenant-scopes}

| 范围 | 包含的内容 |
|---|---|
| **租户级** | 代理技能、工作流及其设计会话、任务模板、工作流执行及其工作流会话、审批、密钥、MCP 服务器、工具模拟、标签、用户组，以及大多数用户 |
| **平台级** | 租户记录本身、[系统设置](../guides/system-settings.md)、超级管理员账户，以及预置的系统用户 |

一位[用户](../guides/users-and-groups.md#users)**最多**属于一个租户。一个[用户组](../guides/users-and-groups.md#user-groups)**恰好**属于一个租户，这正是用户组永远无法授予超级管理员角色的原因：该角色按定义就是平台级的（请参阅[有效角色](./authorization.md#effective-roles)）。首次启动时会创建 **Default** 租户，初始的 `admin` 用户就在其中；初始的 `root` 用户属于平台级，完全没有租户。

## 租户边界 {#the-tenant-boundary}

每一次租户级的读写都在调用方所在的租户内解析，只存在于其他租户的记录会返回 **HTTP 404，而不是 403**：这条边界隐藏记录的存在，而不是宣告它的存在。无论是在 URL 中输入的工作流 ID，还是传给 API 的 ID，都是如此，也正因为这样，跨租户引用永远无法证实记录确实存在。

唯一一种既不返回记录、也不假装记录不存在的读取，是名称批量解析：`POST /api/v1/users/resolve-names` 会从响应中去掉调用方所在租户之外的用户，让 UI 回退为显示原始 ID，但会为两类可以正当地在每个租户内拥有记录的账户加上标签。请参阅[批量解析名称](../guides/users-and-groups.md#users)。

## 以某个租户的身份操作 {#acting-as-a-tenant}

平台级的超级管理员没有自己的租户，而几乎所有值得查看的内容都属于某个租户。应用页眉中的**租户切换器**（仅超级管理员可见）就是用来选择以哪个租户的身份操作的。这一选择在重新加载后仍会保留，并在所有地方生效，包括管理区域和聊天。未选择租户时，租户级请求会以 HTTP 403 被拒绝。

切换租户不会改变*角色*：无论选择了哪个租户，超级管理员仍会绕过所有角色门禁。

切换器只会向自身没有租户的调用方显示。**租户级用户始终限定在自己的租户内**，切换器设置的 `X-Tenant-Id` 标头对他们完全无效，手动发送也不会获得任何权限，因此无法从客户端逃出这条边界。

### 所有租户 {#all-tenants}

切换器还提供**所有租户**选项，可在只读的管理列表页和详情页上同时浏览所有租户的数据。启用后，这些页面会把**租户**列添加为最左侧的一列（并添加相应的字段），以便区分来自不同租户的行。

当您正在代理登录其他用户时，所有租户的选择会被暂时搁置：页面的行为如同选择了该用户自己的租户，也不会显示租户列。停止代理登录后，它会重新生效。

| 选择 | 读取 | 写入 | 聊天历史记录 | 代理端点 |
|---|---|---|---|---|
| 自己的租户（隐式，所有租户级用户） | 自己的租户 | 自己的租户 | 自己的租户 | ✅ |
| 某一个租户（超级管理员） | 该租户 | 该租户 | 该租户 | ✅ |
| **所有租户**（超级管理员） | 所有租户 | ❌ 403 | 所有租户 | ❌ 403 |
| 未选择（超级管理员） | ❌ 403 | ❌ 403 | ❌ 403 | ❌ 403 |

“聊天历史记录”指 `GET /workflows/{id}/messages` 和 `GET /workflow-executions/{id}/messages`，因此超级管理员在审查其他租户的工作流或运行时，也能读取其中的对话。*驱动*这些聊天的代理端点（`POST .../agent`）属于写入操作，始终要求选择一个具体的租户。在所有租户的选择下，工作流 ID 的解析不受租户限制，因此设计会话自身的角色检查在这里代替了租户边界。请参阅[设计会话](./authorization.md#design-session-access)。
