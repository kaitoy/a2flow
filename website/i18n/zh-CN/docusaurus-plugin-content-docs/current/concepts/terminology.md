# 术语

下面这些概念承载了这个领域的大部分内容，值得分清楚：

| 术语 | 含义 |
|---|---|
| **[工作流](../guides/workflows.md)** | 预先设计好、可重复使用的工作单元：一个代理技能，加上为它生成的任务模板。 |
| **设计会话** | 生成并完善工作流任务模板的聊天。每个工作流恰好有一个，并且在任何运行之前就已存在。 |
| **[工作流执行](../guides/workflow-executions.md)** | 工作流的一次运行：保存运行时的工作流和技能元数据快照，同时也是该次运行的 `WorkflowTask`、`Approval` 和消息元数据的父级。 |
| **工作流会话** | 一次工作流执行所在的聊天，是设计会话在运行阶段的对应物。 |
| **分支会话** | 运行的任务图出现分支时，从工作流会话分叉出来的会话，使该分支与运行的其余部分并行推进。其任务完成后，它以一份摘要结束。 |
| **[租户](./tenants.md)** | 最高层级的组织边界：几乎每条记录都恰好属于一个租户，任何请求都不会从一个租户跨入另一个租户。 |
| **[用户组](../guides/users-and-groups.md#user-groups)** | 租户内一组具名的用户，带有一组角色，所有成员都会继承这些角色。 |
| **[标签](../guides/tags.md)** | 在整个租户内通用的标记，用于对密钥、MCP 服务器、代理技能、知识库、工作流、工具模拟和用户组进行分类，这七类记录共用同一套词汇。标记了**访问控制**的标签还会把它所标记的记录限制为仅带有该标签的用户组成员可见。 |
| **[代理技能](../guides/agent-skills.md)** | Git 仓库中的 `SKILL.md` 流程，像代码一样进行版本管理；工作流由它生成，运行时执行的是它已发布的修订版本。 |
| **[知识库](../guides/knowledge-bases.md)** | 由 LLM 根据已注册的网页和文档编写的 Wiki，每个主题一页。与它关联的工作流，其设计代理和执行代理都会在这里查阅资料。 |
| **[MCP 服务器](../guides/mcp-servers.md)** | 已注册的 Model Context Protocol 服务器，代理可以把它的工具绑定到工作流的任务上。 |
| **[密钥](../guides/secrets.md)** | 一组具名的键值凭据条目，在其他地方以 `name/key` 引用，并在使用时才延迟解析。 |
| **[工具证书](../guides/approvals.md#human-approval)** | 任务在每次调用 MCP 工具时都必须出示的短期 X.509 证书。它在签发的那一刻冻结任务的工具集（签发时机是审批获得批准时，或者无需任何人审批的任务启动时），并写明它所代表的是谁的权限。 |
