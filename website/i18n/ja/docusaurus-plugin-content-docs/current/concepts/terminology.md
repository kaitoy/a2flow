# 用語

このドメインの中心となる概念です。区別しておく価値があります。

| 用語 | 何か |
|---|---|
| **[ワークフロー](../guides/workflows.md)** | 再利用できる、事前に設計された仕事の単位。エージェントスキルと、そこから生成されたタスクテンプレートの組。 |
| **設計セッション** | ワークフローのタスクテンプレートを作り、練り上げるチャット。ワークフロー 1 件につきちょうど 1 つあり、実行より先に存在します。 |
| **[ワークフロー実行](../guides/workflow-executions.md)** | ワークフローの 1 回の実行。実行時点のワークフローとスキルのメタデータのスナップショットであり、その実行の `WorkflowTask`、`Approval`、メッセージメタデータの親になります。 |
| **ワークフローセッション** | 1 件のワークフロー実行が行われるチャット。設計セッションの実行時版にあたります。 |
| **[テナント](./tenants.md)** | 最上位の組織境界。ほとんどのレコードはちょうど 1 つに属し、リクエストが一方から他方へまたぐことはありません。 |
| **[ユーザーグループ](../guides/users-and-groups.md#user-groups)** | テナント内のユーザーをまとめた名前つきの束。所属メンバー全員がそのロールを継承します。 |
| **[タグ](../guides/tags.md)** | シークレット、MCP サーバー、エージェントスキル、ワークフローを分類する、テナント共通のラベル。4 つのリソースで 1 つの語彙を共有します。 |
| **[エージェントスキル](../guides/agent-skills.md)** | Git リポジトリに置いた `SKILL.md` の手順書。コードと同じようにバージョン管理され、ここからワークフローが生成されます。実行が動かすのは公開済みのリビジョンです。 |
| **[MCP サーバー](../guides/mcp-servers.md)** | 登録済みの Model Context Protocol サーバー。エージェントはそのツールをワークフローのタスクに結びつけられます。 |
| **[シークレット](../guides/secrets.md)** | キー/値の資格情報エントリをまとめた名前つきの束。ほかの場所からは `name/key` で参照し、使うときに遅延解決されます。 |
| **[承認証明書](../guides/approvals.md#human-approval)** | 承認が与えられたときに発行される、短命な X.509 証明書。判断の瞬間にタスクへ割り当てられていたツールを凍結し、MCP プロキシは、署名つきでこれを提示しないツール呼び出しをすべて拒否します。 |
