# ダッシュボード

ダッシュボードは、テナントのワークフローが今どう動いているかを示します。進行中の実行、承認を待っているもの、失敗したもの、そして実行が開始から完了までにかかる時間です。管理サイドバーの先頭にある**ダッシュボード**を開きます。

開いたままにしておく画面として作られていて、すべての数値は 15 秒ごとに読み直されます。表示は 2 種類あり、選んだほうをブラウザが覚えています。標準表示はアプリのほかの画面と同じ見た目で、ライトとダークのテーマに従います。ミッションコントロール表示は壁掛けのディスプレイ向けです。アプリのほかの部分がどのテーマでも暗いままで、数値が光り、画面のどこかが常に動いています。

次の 2 種類の実行はどの数値にも含まれません。下書きのままのワークフローから開始したテスト実行と、[アクセス制御タグ](./tags.md#access-control-tags)によってあなたから隠されている実行です。

テナントでまだ何も実行していないうちに、数値の入ったダッシュボードを見たい場合は[デモデータ](../getting-started/demo-data.md)を有効にしてください。約 90 日分の架空の実行が登録されます。

## ツールバー {#the-toolbar}

| 操作 | 動作 |
|---|---|
| **ライブ** | 点は数値が最新であることを示します。ミッションコントロール表示では点が脈打ち、次の読み取りが近づくにつれて周りの輪が減っていきます。読み取りに失敗すると**接続が切れました**に変わります。そのとき画面の数値は最後に読み取れたもので、ダッシュボードは再試行を続けます。 |
| **7 日** / **30 日** / **90 日** | **リードタイム**、**ワークフロー別の実行**、**要対応**が対象とする期間を決めます。タイルとほかのパネルは常に現在を示します。 |
| **更新** | すべてを今すぐ読み直します。 |
| **ミッションコントロール表示に切り替える** | ミッションコントロール表示に変えます。**標準表示に切り替える**で戻ります。どちらの表示でも数値は同じです。 |
| **全画面表示** | 画面全体をダッシュボードだけにします。Esc キーか**全画面表示を終了**で戻ります。 |

## タイル {#the-tiles}

各タイルは、1 つの数値、それを補う 1 行、そしてページを開いてからの数値の動きを示す線でできています。ミッションコントロール表示では、数値は変わるたびに一瞬明るく光ります。

| タイル | 数値 | 下の行 | 色が変わるとき |
|---|---|---|---|
| **稼働中の実行** | 進行中の実行(予定されたものを含む) | 過去 24 時間に開始された実行 | 変わりません |
| **保留中の承認** | 判断を待っている承認依頼 | 今日決定された承認 | 24 時間を超えて待っているものがあると琥珀色 |
| **今日の完了** | 今日完了した実行 | 失敗したタスクなしで完了した割合 | 変わりません |
| **失敗した実行(24 時間)** | 過去 24 時間に失敗で終わった実行 | 同じ期間に失敗したタスク | 0 より大きいと赤 |
| **メール送信キュー** | まだ送信されていない[通知メール](./notifications.md#the-delivery-queue) | 最も古いものの待ち時間、または送信に失敗した件数 | 最も古いものが 5 分を超えて待っていると琥珀色、失敗したものがあると赤 |

「今日」はサーバーのタイムゾーンの午前 0 時に始まります。[サーバー設定](../operations/configuration.md#server-settings)を参照してください。

## パネル {#the-panels}

| パネル | 示すもの | 読み方 |
|---|---|---|
| **リードタイム** | 実行の開始から完了までの平均時間を、実行が完了した日ごとに示します。隅の数値は期間全体の平均です。 | グラフにポインターを重ねるか、フォーカスして矢印キーを押すと、1 日分を読めます。何も完了しなかった日には点がありません。 |
| **承認の滞留** | 保留中のすべての承認です。輪の琥珀色の弧は、24 時間を超えて待っている割合です。その下に、待ち時間の長い 5 件が並びます。 | **承認者**と**ワークフロー**を切り替えると、承認が誰を、あるいはどのワークフローを待っているのかがわかります。24 時間を超えて待っている承認が 1 件でもあると、棒は琥珀色になります。 |
| **ワークフロー別の実行** | 期間内に開始された実行の多い順に、8 つのワークフローを示します。各棒は**完了**、**失敗**、**実行中**に分かれます。 | 行の端の数値はその実行数で、ワークフローの平均リードタイムの隣にあります。区間にポインターを重ねると件数が出ます。 |
| **失敗の原因** | 過去 24 時間に失敗したタスクを、それぞれに記録された原因別に示します。 | 凡例に、該当する原因とその件数がすべて並びます。 |
| **要対応** | 期間内に失敗したタスクのある実行を、新しい順に原因とともに示します。管理者にだけ表示されます。 | 実行をクリックすると開きます。帯を横にスクロールすると残りを見られます。ミッションコントロール表示では帯が自動で流れ、ポインターを重ねている間は止まります。 |

## 誰に見えるか {#who-sees-it}

**ダッシュボード**は、管理者、開発者、依頼者、承認者のサイドバーに表示されます。テナントについて誰もが同じ数値を見ます。**要対応**だけは管理者に限られます。見ている人が関わっていない実行のタスク名と失敗の原因を引用するためです。

同じ数値を自前の監視ツールでグラフにしたい場合は、[運用メトリクス](../operations/metrics.md)を参照してください。
