# Per-tenant OIDC SSO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each tenant register one OIDC IdP so its staff sign in with their company account, with just-in-time user creation and IdP-group → user-group sync.

**Architecture:** A pure OIDC client (`infrastructure/oidc_client.py`, httpx + pyjwt) does discovery, code exchange and ID-token validation. `services/oidc_login.py` owns the start/complete use cases: state cookie, user resolution/linking/creation, group sync, then a session minted by the existing `AuthService`. Two unguarded routes on the `auth` router redirect the browser; the frontend only adds a button, settings fields and translations.

**Tech Stack:** FastAPI, SQLModel, Alembic, httpx, pyjwt[crypto] 2.15.1, cryptography (Fernet via `SecretCipher`), Next.js 16, Vitest/MSW, Docusaurus.

**Spec:** `docs/superpowers/specs/2026-11-10-oidc-sso-design.md`

## Global Constraints

- No new packages. Add `"pyjwt[crypto]>=2.15.1"` to `backend/pyproject.toml` dependencies (already in `uv.lock`); run `uv lock` and confirm only the root package entry changes.
- Every IdP HTTP call uses an `httpx.AsyncClient` whose request hook runs `guard_peer_address` unless the host is in `OIDC_ALLOWED_PRIVATE_HOSTS`. Never `PyJWKClient` (it uses urllib, bypassing the guard).
- SSO error codes, exactly: `unavailable`, `failed`, `account_disabled`, `not_permitted`.
- Scopes, exactly: `openid email profile`. State cookie lifetime: 600 s. Discovery/JWKS cache TTL: 300 s. ID-token clock leeway: 60 s.
- Redirect URI: `{app_base_url}/api/v1/auth/oidc/callback` (`app_base_url` from the `system_settings` row, trailing `/` stripped).
- New docstrings (Google style) / JSDoc on every new or changed symbol; English everywhere except `website/i18n/`.
- No hardcoded GUI text; every new key in all six catalogs under `frontend/src/i18n/messages/`.
- Migrations: `op.batch_alter_table`, explicit constraint names, SQLite + PostgreSQL.
- Every new `HttpMappedError` gets a row in `.claude/rules/backend-patterns.md`'s Error Mapping table and `errors.<CODE>` in all six catalogs.

## Review Focus

1. **Replay / mix-up**: a valid state cookie from tenant A presented with a callback `state` from another attempt → `failed`; covered in Task 6.
2. **E-mail case and whitespace**: `Alice@Example.com ` from the IdP vs `alice@example.com` stored → links; covered in Task 5.
3. **Username normalisation edge**: `preferred_username` `"j"` (too short) or `"山田"` (no slug chars) → falls back to the e-mail local part, then to `user`, padded to ≥3 and deduplicated; covered in Task 5.
4. **Groups claim not a list** (string, or missing entirely) → a string is treated as a one-element list, missing as empty; covered in Task 5.
5. **Second login after an admin set a password** on an SSO user → SSO still resolves by `sub`; password login also works; covered in Task 5.

### Task 4: OIDC client

**Files:**
- Create: `backend/infrastructure/oidc_client.py`, `backend/tests/_oidc_fake.py`
- Modify: `backend/dependencies/singletons.py`
- Test: `backend/tests/test_oidc_client.py`

**Interfaces:**
- Consumes: Task 2 `Settings.oidc_allowed_private_hosts`, `assert_public_http_url(..., allowed_hosts=)`, `guard_peer_address`.
- Produces:
  - `class OidcError(Exception)` — message is log-only.
  - `@dataclass(frozen=True) class OidcProviderMetadata: issuer: str; authorization_endpoint: str; token_endpoint: str; jwks_uri: str; userinfo_endpoint: str | None`.
  - `class OidcClient:`
    - `__init__(self, http: httpx.AsyncClient, *, allowed_hosts: Collection[str]) -> None`
    - `async def metadata(self, issuer: str) -> OidcProviderMetadata` — GET `{issuer.rstrip('/')}/.well-known/openid-configuration`; requires document `issuer` == configured issuer (exact string); each endpoint passes `assert_public_http_url(..., allowed_hosts=)`; cached 300 s per issuer.
    - `def authorization_url(self, meta, *, client_id: str, redirect_uri: str, state: str, nonce: str, code_challenge: str) -> str` — `response_type=code`, `scope=openid email profile`, `code_challenge_method=S256`.
    - `async def exchange_code(self, meta, *, client_id: str, client_secret: str, code: str, redirect_uri: str, code_verifier: str) -> dict[str, Any]` — `client_secret_post`; non-2xx or no `id_token` → `OidcError`.
    - `async def validate_id_token(self, meta, id_token: str, *, client_id: str, nonce: str) -> dict[str, Any]` — keys from `jwks_uri` (cached 300 s, refetched once on unknown `kid`) via `jwt.PyJWKSet.from_dict`; `jwt.decode(algorithms=[RS256, RS384, RS512, ES256, ES384, PS256], audience=client_id, issuer=meta.issuer, leeway=60, options={"require": ["exp", "iat", "sub"]})`; nonce mismatch → `OidcError`. Every `jwt` exception becomes `OidcError`.
    - `async def userinfo(self, meta, access_token: str) -> dict[str, Any]` — `{}` when `userinfo_endpoint` is None.
  - `def make_pkce_pair() -> tuple[str, str]` — `(verifier, S256 challenge)`, verifier from `secrets.token_urlsafe(48)`.
  - `get_oidc_client() -> OidcClient` (`@lru_cache` singleton, `httpx.AsyncClient(timeout=10, event_hooks={"request": [hook]})` where `hook` skips `guard_peer_address` for allowed hosts); `OidcClientDep`.
